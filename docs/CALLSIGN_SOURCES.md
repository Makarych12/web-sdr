# Проверка источников позывных — 11 октября 2026

Короткий вывод: среди проверенных вариантов подтверждён полностью бесплатный документированный API Callook, разрешающий использование на стороннем сайте, но только для США. Для украинских позывных бесплатная разрешённая замена HamQTH с проверенным актуальным владельцем пока не найдена. Это исследование не подтверждает совпадение UR4MTN с актуальной полной записью QRZ.com: она недоступна без входа. HamQTH и его Production env сохраняются.

«Не проверено» не означает «позывной отсутствует». Публичная страница, API и право повторной публикации — разные вещи. Данные из поискового индекса и старых рассылок не используются для заполнения карточки.

## QRZ.RU: отдельная проверка

1. Документированный XML API есть; открытый экспорт не обнаружен.
2. Нужны регистрация, постоянный позывной в коллбуке и отдельный XML-аккаунт.
3. API разрешён только персональным журналам; WebSDR требует отдельного разрешения.
4. UR4MTN найден (HTTP 200), сведения сокращены; полное совпадение с QRZ.com не проверено.
5. UR4MAD найден (HTTP 200); страна расходится с QRZ.com. Владелец автоматически не выбирается.
6. Есть суточный счётчик обновлений; даты этих записей и SLA без входа не установлены.
7. Один запрос/3 секунды, без параллельных соединений. Защита не обходилась; production-парсер HTML не создавался.
8. Атрибуцию публичного использования нужно согласовать вместе с разрешением; правила рассылки не распространяем на API.

Публичные страницы: [UR4MTN](https://m.qrz.ru/callbook?q=UR4MTN), [UR4MAD](https://m.qrz.ru/callbook?q=UR4MAD). Контроль QRZ.com: [UR4MTN](https://www.qrz.com/db/UR4MTN), [UR4MAD](https://www.qrz.com/db/UR4MAD). Правила [QRZ.com](https://www.qrz.com/page/qrz_terms.html) запрещают автоматическое копирование страниц; HTML lookup не подключается.

## Решение

Подключить Callook как дополнительный источник для достоверных американских записей, сохранив HamQTH. QRZ остаётся первым при настроенном разрешённом доступе; подтверждённый ответ не заменяется. Ограниченный по стране отрицательный ответ не является глобальным отсутствием. Каждый ответ принадлежит одному источнику целиком, получает время получения. Другие адаптеры добавляются через единый интерфейс после проверки условий. Противоречия анализируются явно, без автоматической склейки или выбора владельца.

## Проверка реализации

- 61 автоматический тест и production build проходят. Отдельно проверены истёкшая сессия QRZ (обновление один раз), техническая недоступность, отрицательный cache и отсутствие смешивания владельцев; эти сценарии проверены тестовыми ответами, а не реальными чужими учётными данными.
- Реальные запросы через новый backend: W1AW — found, Callook, ARRL HQ OPERATORS CLUB. UR4MTN, UR4MAD, UR5EQF, UT5URW, DL1ABC, JA1ABC, VK2ABC и ZZ0ZZZZ — недоступен международный источник; отрицательный Callook не превращается в глобальное «не найден».
- Реальный W1AW в карточке: мышь desktop и касание mobile; источник/время получения и Escape проверены. Геометрия основных блоков совпадает с прежним production на 1440/820/390/320 px, горизонтального переполнения нет. Проверены все шесть шагов на пяти ширинах экрана.
- Реальный KiwiSDR, AM, колесо VFO 20 секунд: 188/188 ненулевых аудиоинтервалов, 0 underrun, 0 reset, один AudioContext/AudioWorklet; spectrum +173 кадра, waterfall продолжает обновляться. Это проверка PCM, не заявление о прослушивании человеком или повторном прогоне всех режимов.
- Сканирование известных локальных секретов в отслеживаемых файлах и frontend bundle: совпадений нет. Наличие обеих переменных HamQTH в Vercel проверено; значения не выгружались.

Полная актуальная запись UR4MTN в QRZ.com и работоспособный международный источник для украинских/японских/австралийских контрольных позывных остаются непроверенными. Подключение американского API не решает эти ограничения.
